# Multimedia Datasets

## 📁 Dataset Catalog

### 1. 🖼️ Images (`datasets/images/`)
- **`flower.jpg`**: High-resolution image (720x1600) for EXIF and spatial testing.
- **`flower2.jpg`**: Secondary test image for comparative evaluation.

### 2. 🎵 Audio (`datasets/audio/`)
- **`Afternoon_Window.mp3`**: MP3 audio sample for stream decoding, bitrate calculation, and tag extraction.

### 3. 🎥 Video (`datasets/video/`)
- **`voiceover.mp4`**: Synchronized MP4 container (H.264/AAC) for demuxing and frame analysis.
